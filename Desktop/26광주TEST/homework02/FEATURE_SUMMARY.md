# Todo 앱 주요 기능 요약

## 앱 개요

- HTML, CSS(Tailwind CDN), JavaScript로 만든 기본 Todo 앱입니다.
- 첫 화면은 Todo 목록이 비어 있으며, 사용자가 직접 추가한 항목만 표시됩니다.
- `index.html` 실행만으로 동작합니다.

## 핵심 기능

1. **Todo 입력**
   - 입력창에 할 일을 텍스트로 입력할 수 있습니다.

2. **Todo 추가**
   - `추가` 버튼 클릭 시 새로운 Todo가 목록에 추가됩니다.

3. **빈 값 방지**
   - 공백만 입력하거나 비어 있으면 `alert("할 일을 입력해주세요.")`가 표시되고 추가되지 않습니다.

4. **Todo 목록 표시**
   - `todos` 배열 데이터를 기준으로 목록이 화면에 렌더링됩니다.

5. **완료/미완료 변경**
   - 각 항목의 체크박스로 완료 상태를 바꿀 수 있습니다.
   - 체크됨 = 완료, 체크 해제 = 미완료

6. **Todo 삭제**
   - 각 항목의 휴지통 아이콘 버튼 클릭 시 해당 Todo가 삭제됩니다.

7. **화면 자동 갱신**
   - 추가/완료변경/삭제가 발생하면 `renderTodos()`가 다시 실행되어 화면이 즉시 갱신됩니다.

8. **기본 UI 구성**
   - 연한 회색 배경 + 중앙 카드형 레이아웃
   - 카드 내부 구성: 제목, 입력창, 추가 버튼, Todo 목록, 하단 통계
   - 모바일에서도 깨지지 않도록 반응형으로 구성

## 화면 표시 규칙

- 각 Todo 항목 구조:
  - `[체크박스] [할 일 텍스트] [휴지통 아이콘]`
- 완료된 항목은 텍스트에 취소선과 흐린 색상이 적용됩니다.
- 하단 통계 영역에 `총 개수 / 완료 개수`가 표시됩니다.

## 사용된 주요 함수

- `addTodo()`: 입력값 검증 후 새 Todo 추가
- `renderTodos()`: 현재 배열 상태를 기준으로 목록 다시 그리기
- `toggleTodo(id)`: 완료 상태 토글
- `deleteTodo(id)`: Todo 삭제

## 제외된 기능 (요구사항 준수)

- localStorage 저장 기능 없음
- 검색 기능 없음
- 필터 기능 없음
- 수정 기능 없음
