# AI 프롬프트 로그

## 프로젝트명
- Netflix 스타일 다크 무드 영상 콘텐츠 랜딩 페이지

## 작업 목표
- HTML/CSS만 사용해 랜딩 페이지를 제작한다.
- 구조는 `Header`, `Hero Section`, `Card Section`, `Footer`로 구성한다.
- 반응형(모바일 기준 768px 이하)과 카드 레이아웃 정리를 통해 제출 가능한 완성 상태로 만든다.

## 사용 기술
- HTML5 (시맨틱 태그: `header`, `main`, `section`, `footer`)
- CSS3 (Flex, Grid, `aspect-ratio`, 반응형 미디어쿼리, hover transition)
- JavaScript 미사용

## 프롬프트 사용 순서
1. 기본 HTML 뼈대 생성 요청
2. Netflix 무드 레이아웃 구조화 요청 (`index.html`, `style.css`)
3. Hero Section 디자인 강화 요청
4. Hero 콘텐츠 정렬(왼쪽 가운데) 수정 요청
5. 카드 섹션 디자인/가로 스크롤 보완 요청
6. 카드 섹션을 Grid 기반으로 재구성 요청 (8/4/2 규칙)
7. 카드 이미지/개수/alt 및 레이아웃 재조정 요청 (5/3/2 규칙)
8. 카드 개수별 가로 폭 균등 분배 요청 (Originals 5, Trending 4)
9. 푸터 및 전체 마무리 스타일 통일 요청
10. 썸네일 미노출 문제 해결 요청 (이미지 경로 교체)
11. 제출용 `prompt-log.md` 생성 요청

## 단계별 프롬프트 내용 요약 및 수정 결과

### 1) 기본 구조 생성
- **프롬프트 목적**: 페이지의 최소 구조를 빠르게 만들기
- **요약**: 헤더, 히어로, 카드, 푸터가 있는 기본 HTML 생성 요청
- **수정 결과**:
  - `index.html` 생성
  - 섹션별 기본 마크업과 `style.css` 링크 준비

### 2) Netflix 스타일 구조 확장
- **프롬프트 목적**: 디자인 이전 단계에서 전체 레이아웃 골격 고도화
- **요약**: 고정 헤더, 히어로 비주얼, 카드 섹션 2개, 푸터를 반응형 구조로 구성 요청
- **수정 결과**:
  - `index.html` 전체 구조 정비
  - `style.css` 신설(리셋, 다크 톤, 헤더/히어로/카드/푸터 기본 스타일)
  - 모바일에서 메뉴 숨김 + 햄버거 버튼 노출 구조 반영

### 3) Hero Section 강화
- **프롬프트 목적**: 첫 화면 임팩트 개선
- **요약**: 커버 배경, 좌→우 오버레이, 버튼 대비, 하단 그라데이션, 모바일 타이포 조정 요청
- **수정 결과**:
  - 히어로 높이/타이포 강화
  - 오버레이 및 버튼 스타일 강화
  - 설명 문구 2줄 제한 처리

### 4) Hero 정렬 미세 수정
- **프롬프트 목적**: 콘텐츠 위치 정합성 맞추기
- **요약**: 히어로 콘텐츠를 왼쪽 가운데 정렬로 변경 요청
- **수정 결과**:
  - `.hero-content` 정렬을 하단 기준에서 중앙 기준으로 변경

### 5) 카드 섹션 스크롤/상호작용 보완
- **프롬프트 목적**: 카드 구역 가독성과 인터랙션 강화
- **요약**: 가로 정렬, 스크롤바 처리, hover 확대, 모바일 스크롤 개선 요청
- **수정 결과**:
  - 카드 간격 및 hover 효과 정비
  - 스크롤 관련 스타일 보완

### 6) 카드 섹션 Grid 전환
- **프롬프트 목적**: 스크롤 대신 고정 그리드 배치로 변경
- **요약**: PC 8개/태블릿 4개/모바일 2개, 이미지 `img` 적용 요청
- **수정 결과**:
  - 카드 레이아웃을 Grid로 전환
  - `img` 태그 기반 카드 구조로 변경

### 7) 카드 개수/alt/비율 재조정
- **프롬프트 목적**: 과제 조건(개수/문구/비율) 정합성 확보
- **요약**:
  - Originals 5개, Trending 4개
  - 가상 콘텐츠명 alt
  - 비율 유지(`2/3`, `16/9`) 및 object-fit 적용
  - PC 5개, 태블릿 3개, 모바일 2개
- **수정 결과**:
  - 카드 수량/alt 텍스트 수정
  - 반응형 열 수 재설정

### 8) 카드 개수별 폭 균등 분배
- **프롬프트 목적**: 섹션별 카드 수 차이로 생기는 빈 공간 해결
- **요약**: 카드 개수에 맞게 한 줄 전체를 균등 분배하도록 요청
- **수정 결과**:
  - `.poster-list`는 5열, `.thumbnail-list`는 4열로 분리
  - 우측 빈 칸이 덜 어색하게 보이도록 레이아웃 정리

### 9) 푸터 및 전체 마무리
- **프롬프트 목적**: 제출 전 완성도 향상
- **요약**: 푸터 콘텐츠 확장, 간격/폰트 통일, 가로 스크롤 방지 요청
- **수정 결과**:
  - 푸터에 브랜드 설명/링크/카피라이트/`202605_01HOMEWORK SINHYE` 반영
  - 공통 spacing/typography 변수 정리
  - `body` 가로 스크롤 방지 처리

### 10) 썸네일 미노출 이슈 해결
- **프롬프트 목적**: 카드 이미지 실제 표시
- **요약**: “썸네일이 없다” 문제 해결 요청
- **수정 결과**:
  - 로컬 임시 경로(`images/...`)를 즉시 표시 가능한 placeholder URL로 교체
  - 포스터/썸네일 비율에 맞는 해상도 URL 적용

### 11) 제출 문서화
- **프롬프트 목적**: 작업 과정 증빙 문서 작성
- **요약**: `prompt-log.md`를 기준 형식에 맞춰 생성 요청
- **수정 결과**:
  - 현재 문서(`prompt-log.md`) 생성 완료

## 시행착오 또는 수정 요청 내용
- 카드 섹션 요구사항이 단계마다 변경됨
  - 초기: 가로 스크롤 중심
  - 이후: Grid 고정 배치
  - 이후: PC 8열 → PC 5열
  - 이후: 섹션별 카드 수 기반 균등 분배(5열/4열 분리)
- 이미지 표시 이슈 발생
  - 원인: `images/poster-*.jpg` 파일이 실제로 없으면 브라우저에 표시되지 않음
  - 조치: 테스트 가능한 placeholder URL로 교체해 즉시 확인 가능하게 수정
- Hero 정렬 방향 재요청
  - 하단 정렬에서 왼쪽 가운데 정렬로 변경

  - 가로 스크롤 방지 및 전체 간격/타이포 통일 완료
